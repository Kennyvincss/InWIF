# Security policy

InWIF is pre-release software and has **not** been independently audited.

Please report vulnerabilities privately using GitHub's "Report a vulnerability" (Security Advisories)
on this repository. Do not open public issues for security problems. Include reproduction steps and the
affected component (core, web, api, contracts, firmware, mobile, desktop).

InWIF will never ask for your recovery phrase or private key. Anyone who does is attempting to steal funds.
